# 施富凱 系統作品集

刑事警察 × AI 協作開發者的個人履歷作品集網站。

- 線上瀏覽：https://shihfukai.github.io/
- 20 套自行開發系統，每套皆可線上互動體驗（示範資料）
- 右上角「匯出履歷」可下載 A4 履歷作品集 PDF

## 更新內容

所有內容集中在 `index.html` 的「資料區」：

- `PROFILE`：姓名、職稱、摘要、聯絡方式
- `SYSTEMS`：系統作品（`status`：live 使用中／dev 開發中／plan 規劃中）
- `CREDENTIALS`：證照與證書（`hi: true` 以金色突顯）
- `EDUCATION`、`EXPERIENCE`：學歷與經歷

目前設定 `noindex`，不會出現在 Google 搜尋結果；要開放搜尋時，刪除 `<meta name="robots" content="noindex">` 這一行即可。
